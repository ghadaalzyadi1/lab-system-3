# 🔬 منصة إدارة أجهزة المختبر ومتابعة المعايرة

منصة ويب حديثة (عربية، RTL) لإدارة أجهزة المختبر ومتابعة مواعيد المعايرة،
معبّأة ببيانات المختبر الحقيقية من ملف المعايرة لعام 2026.

## ✨ المزايا

- **لوحة تحكم** بإحصائيات حيّة، رسوم بيانية (Chart.js)، وتنبيهات المعايرة.
- **إدارة الأقسام والأجهزة** — كل قسم مقسوم إلى **أجهزة رئيسية ⭐** و**أجهزة مساندة 🔧**.
- **بطاقة بيانات كاملة لكل جهاز** (المصنّع، الموديل، الرقم التسلسلي، الفحص، الشهادة، تواريخ المعايرة…).
- **متابعة المعايرة والتنبيه المسبق** — حالة تلقائية: سارية / تنتهي قريباً / منتهية (فترة التنبيه قابلة للضبط).
- **رفع وعرض شهادات المعايرة** (PDF أو صور) مع عرض داخل الصفحة.
- **رمز QR لكل جهاز** — قابل للتحميل والطباعة للوصول السريع.
- **مسح QR من الكاميرا** وتحديث حالة تشغيل الجهاز مباشرةً.
- **صلاحيات المستخدمين** — ثلاثة أدوار: مدير نظام / فني مختبر / مشاهد.
- **تقارير** قابلة للتصفية مع تصدير CSV وطباعة.
- **سجل زمني** لكل جهاز يوثّق المعايرات وتغييرات الحالة.

## 🚀 التشغيل

لا تحتاج خادماً — افتح `index.html` في المتصفح مباشرةً
(أو استضفه كموقع ثابت عبر GitHub Pages / Netlify / أي استضافة static).

## 🗂️ البنية

| الملف | الوصف |
|------|-------|
| `index.html` | هيكل التطبيق وتحميل المكتبات |
| `styles.css` | التصميم (حديث، RTL) |
| `seed-data.js` | بيانات الأقسام والأجهزة المستخرجة من ملف المختبر |
| `db.js` | طبقة البيانات — `localStorage` للبيانات و`IndexedDB` للشهادات |
| `auth.js` | المستخدمون والأدوار والصلاحيات |
| `app.js` | الموجّه (SPA) وكل الشاشات |

## 💾 تخزين البيانات

التطبيق **يعمل بالكامل في المتصفح** ويخزّن البيانات محلياً:
- البيانات المنظّمة في `localStorage`.
- ملفات الشهادات في `IndexedDB`.

> هذا يجعل المنصة تعمل فوراً دون إعداد خادم. ولأن التخزين محلي لكل متصفح،
> فإن البيانات لا تتزامن بين الأجهزة. للاستخدام المشترك متعدد المستخدمين
> يمكن لاحقاً ربط طبقة `db.js` و`auth.js` بخلفية حقيقية (مثل Supabase أو أي REST API).

لاستعادة البيانات الأصلية في أي وقت: **الإعدادات → استعادة البيانات الأصلية**.

- **72 جهازاً** (24 رئيسي، 48 مساند) من ملف المعايرة الفعلي.
